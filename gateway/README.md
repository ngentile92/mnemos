# mnemos-hub

The Python package behind [Mnemos](https://github.com/ngentile92/mnemos): one memory, skills and credentials hub
for all your AI assistants (Claude, ChatGPT, Cursor…), isolated by context, over MCP.

```bash
uvx --from mnemos-hub mnemos-local init      # creates ~/Mnemos
uvx --from mnemos-hub mnemos-local serve     # http://127.0.0.1:8765
```

Most people want the Mac app instead: see the [install guide](https://github.com/ngentile92/mnemos/blob/main/docs/INSTALL-mac.md).
