    How to read this
    • Each space (Personal, Work…) is a galaxy with its own halo. Things in several spaces sit between them as bridges (white ring).
    • A dot is a person, project, place, tool or topic named in your notes; its size is how much it matters (how many notes mention it).
    • A line means two things appear together; a relation reads subject — relation → object, the way it was found.
    • Relations found by a model can be wrong. When in doubt, open the notes behind a dot: they are the source of truth.
    • Drag to move (neighbours follow), scroll to zoom, double-click to fit, shift-click two dots to see how they connect.

    Advanced auto-capture, built-in memory for coding apps, activity

    Auto-capture

    Chat apps save when they notice something. Coding apps can do better: with auto-capture on, every message you send is kept on this computer (no AI reads it at that moment, code and pasted logs are dropped) and, once the chat goes quiet, Mnemos keeps the lasting facts in Recently learned, where you can undo any of them. New chats also start knowing your profile. Pausing the app in the list above pauses this too.

    Built-in memory for coding agents

    opt-in

    Write your profile where Claude Code, Codex and Cursor already look, so every session starts knowing you even before it calls Mnemos. Only the spaces you pick; Mnemos keeps a backup of any file it touches and only writes its own part (in Codex's AGENTS.md, a marked block). Turning it off removes exactly what Mnemos wrote.

    What does each job now

    on this Mac unless you add a key
    Technical details

    Order: an API key you enabled for that feature → Ollama (if running) → the built-in model → Apple Intelligence (import only) → simple rules. Search similarity never uses an API.

    Apple Intelligence

    Apple's model on this Mac: nothing to download. It only helps when bringing in chats; it does not name the topics on your map or tidy up your notes. The private model above does all of that.

    Use an API key (optional)

    With an API key, the text being imported or cleaned up leaves this Mac and is sent to OpenAI or Anthropic under their terms. Only the features you tick below use it. The key is kept in the macOS Keychain.

    Advanced reach from the web and phone, memory store, Labs

    Reach from anywhere

    off

    Lets AI apps that run in the cloud (Claude on the web and on your phone, ChatGPT, Grok) use your memory through Tailscale Funnel, a free secure tunnel to this computer. Each app signs in with your Mnemos password and you choose which spaces it may use.

    Your computer has to be on, awake and running Mnemos. When it sleeps or Mnemos is closed, those apps cannot reach your memory (they will say so). Apps on this computer are not affected.

    Labs
    optional extras

    Memory model
    
    
    Mnemos links each note to who or what it is about (you, a person, a project, a tool) so it can build your profile, keep only the current version of a fact and explain why a note was used. Notes are never rewritten or deleted by this: try it first, and undo it any time.
