Add or correct something

Write a fact in one sentence. Mnemos first looks for a note that says otherwise: if one does, it proposes a minimal fix you can apply; if none does, you can save it as a new note. Nothing is written until you click.

Engine

what does the smart parts

Order: an API key you enabled for that feature → Ollama (if running) → the built-in model → Apple Intelligence (import only) → simple rules. Search similarity never uses an API.

Built-in model

Runs on this Mac (Apple Silicon: uses the GPU). Stored in your Mnemos folder; nothing is sent anywhere.

Apple Intelligence

Apple's on-device model (macOS 26 with Apple Intelligence on). Nothing to download; used to find facts when the built-in model is not installed. The built-in model finds more useful facts.

Use an API key (optional)

With an API key, the text being imported or cleaned up leaves this Mac and is sent to OpenAI or Anthropic under their terms. Only the features you tick below use it. The key is kept in the macOS Keychain.

Nothing is saved until you review the list and click “Save”. Duplicates are skipped.

Scan this Mac

Finds what your AI tools already know about you. Files are only read, never changed; anything that looks like a password or key is left out. You pick the sources and the context, then review every note.

Full history

Reads every chat of the selected sources in the background (the scan above only reads the newest ones). You can keep using Mnemos, quit and come back: it continues where it stopped, and next time it only reads what is new. Nothing is saved until you approve it here.

Memories that live in the cloud

Claude.ai and ChatGPT keep their memory online. One click copies a ready question and opens the site: paste it in a new chat, copy the answer, paste it below.

From ChatGPT

ChatGPT → Settings → Data controls → Export data. You get an email with a .zip: pick that file (or the conversations.json inside). Only things you said about yourself are proposed.
