# mnemos-hub (npm)

`npx mnemos-hub init` then `npx mnemos-hub serve`: a launcher for the [Mnemos](https://github.com/ngentile92/mnemos)
local hub (Python package `mnemos-hub` on PyPI, run through [uv](https://docs.astral.sh/uv/)).
On a Mac, prefer the app: [Mnemos-macos.dmg](https://github.com/ngentile92/mnemos/releases/latest/download/Mnemos-macos.dmg).
